## 원칙

**색을 아낀다.** 화면의 대부분은 무채색이고, 위계는 **보더 + 텍스트 3단계 + 여백**으로 만든다.
강조색(파랑)은 드물게 쓸수록 강조 기능을 한다. 남발하면 아무것도 강조되지 않는다.

**강조색을 쓰는 곳 — 이게 전부다.**

| 쓴다                           | 쓰지 않는다 |
| ------------------------------ | ----------- |
| primary 버튼 (화면당 보통 1개) | 아바타      |
| 입력 포커스 링                 | 보조 버튼   |
| 링크 · 멘션                    | 카드 강조   |
| 선택된 항목 표시               | 아이콘      |

## 표면 · 텍스트

| 용도                        | 라이트    | 다크      |
| --------------------------- | --------- | --------- |
| 표면 1 (카드 · 헤더 · 패널) | `#ffffff` | `#0a0a0a` |
| 표면 2 (페이지 배경)        | `#fafafa` | `#000000` |
| 표면 3 (선택된 항목)        | `#f2f2f2` | `#141414` |
| 호버 (ghost 버튼 · 목록 행) | `#f0f0f0` | `#1c1c1c` |
| 텍스트 1 (본문)             | `#171717` | `#ededed` |
| 텍스트 2 (보조)             | `#666666` | `#a1a1a1` |
| 텍스트 3 (흐림 · 캡션)      | `#8f8f8f` | `#737373` |
| 보더                        | `#eaeaea` | `#1f1f1f` |

**다크 배경은 순수 블랙 계열이다.** 페이지가 `#000000`, 카드가 `#0a0a0a`로 카드가 미세하게 밝다.
표면 대비를 낮게 잡아 배경이 튀지 않게 하고, 면의 구분은 **보더**가 맡는다.

**다크 본문 텍스트가 순백(`#ffffff`)이 아니다.** `#ededed`를 쓴다.
순수 블랙 위의 순백은 대비가 과해 눈이 피로하다.

## 메서드 뱃지

**라이트와 다크의 처리가 다르다.**

- **라이트 = 솔리드** (원색 배경 + 흰 글자). 흰 화면에서 옅은 틴트는 거의 보이지 않는다.
- **다크 = 아웃라인** (밝은 글자 + 옅은 배경 + 보더). 블랙 배경에서 솔리드는 혼자 튄다.

### 라이트 (솔리드)

| 메서드 | 배경 · 보더 | 글자      |
| ------ | ----------- | --------- |
| GET    | `#52ab1f`   | `#ffffff` |
| POST   | `#2b8fe6`   | `#ffffff` |
| PUT    | `#e08c1a`   | `#ffffff` |
| PATCH  | `#12b48c`   | `#ffffff` |
| DELETE | `#ef5350`   | `#ffffff` |

채도를 올린 만큼 흰 글자가 묻히기 쉬우므로 **글자 굵기 700 + 자간 확대**로 보정한다.

### 다크 (아웃라인)

| 메서드 | 글자      | 배경 (알파 13%)        | 보더 (알파 32%)        |
| ------ | --------- | ---------------------- | ---------------------- |
| GET    | `#8fc75c` | `rgba(99,153,34,.13)`  | `rgba(99,153,34,.32)`  |
| POST   | `#6fb4e8` | `rgba(55,138,221,.13)` | `rgba(55,138,221,.32)` |
| PUT    | `#d99b45` | `rgba(186,117,23,.13)` | `rgba(186,117,23,.34)` |
| PATCH  | `#4fc3a1` | `rgba(29,158,117,.13)` | `rgba(29,158,117,.32)` |
| DELETE | `#ef7a79` | `rgba(226,75,74,.13)`  | `rgba(226,75,74,.32)`  |

### 컴포넌트에는 분기가 없다

`MethodBadge`는 CSS 변수만 참조하고, `.dark`에서 **값만 바뀐다.**

```
--sn-get-fg / --sn-get-bg / --sn-get-border
→ text-get-fg  bg-get-bg  border-get-border
```

뱃지 폭은 `min-w-[52px]`로 맞춰 목록에서 경로가 세로로 정렬되게 한다.

**색 매핑(GET 초록 · POST 파랑 · DELETE 빨강)은 업계 관례다.**
Swagger UI · Postman · Stoplight이 공유한다. 차별화하면 학습 비용만 늘어난다.

## 버튼

| 종류        | 스타일                                                                   | 쓰는 곳                                            |
| ----------- | ------------------------------------------------------------------------ | -------------------------------------------------- |
| **primary** | 파랑 채움 + 흰 글자                                                      | 화면의 주 액션. 보통 화면당 1개.                   |
| **ghost**   | 보더 없음 · 배경 없음.<br>호버 시 회색 배경, 포커스 시 파란 1px 아웃라인 | 그 외 전부 — 보조 버튼 · 아이콘 버튼(`←` `⚙` `🔍`) |

**보조 버튼에 아웃라인을 두지 않는다.**
헤더처럼 아이콘 버튼이 여럿 모이는 곳에서 박스가 늘어서면 시각적 소음이 크다.
평소엔 아이콘만 떠 있고, 상호작용할 때만 배경이 나타난다.

호버는 마우스 사용자를 위한 것이고, 포커스 링(파란 1px)은 키보드 사용자를 위한 것이다.
둘 다 필요하다.

## radius

**3px로 통일한다.** 카드 · 입력 · 버튼 · 뱃지 · 호버 하이라이트가 모두 같다.

`--radius: 3px`이고 `--radius-sm/md/lg/xl`도 전부 3px로 고정했으므로,
shadcn 컴포넌트가 `rounded-md`를 쓰더라도 3px로 나온다.

**아바타만 예외** — 원형(`rounded-full`).

## 폰트

```
Geist (라틴) → Pretendard (한글) → system-ui
```

둘 다 CDN. Geist는 Google Fonts, Pretendard는 jsDelivr.
`@import`는 CSS 파일 **최상단**에 있어야 적용된다.

```css
@import url("https://fonts.googleapis.com/css2?family=Geist:wght@400;500;600;700&display=swap");
@import url("https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.css");
```

```css
--font-sans: "Geist", "Pretendard", system-ui, sans-serif;
```

Geist에는 한글 글리프가 없다. 라틴은 Geist가, 한글은 Pretendard가 렌더한다.

## 한글 타이포그래피 규칙

**한글은 같은 px에서 라틴보다 작아 보인다.**
라틴은 x-height가 커서 12~13px에서도 읽히지만,
한글은 자음+모음 조합이라 획이 뭉개져 답답해진다.

| 규칙   | 내용                                                                                                                      |
| ------ | ------------------------------------------------------------------------------------------------------------------------- |
| 크기   | 한글 위주 UI 텍스트는 라틴 기준보다 **1~2px 크게**. 본문은 `text-sm`(14px)을 기본으로, `text-xs`(12px)는 라벨 · 캡션에만. |
| 줄간격 | 라틴보다 **넉넉하게**. `leading-relaxed` 계열을 기본으로.                                                                 |
| 예외   | 엔드포인트 경로 · 코드 · 숫자 등 **라틴 전용 영역은 작게 써도 된다** (모노스페이스 포함).                                 |

밀도를 높이려다 한글을 작게 잡으면 화면이 촘촘해 보이는 게 아니라
**읽기 불편하고 조악해 보인다.** 밀도는 여백과 간격으로 조절하고, 글자는 줄이지 않는다.

## 다크 모드

`<html>`에 **`.dark` 클래스**를 붙였다 뗀다 (shadcn 표준).
`ThemeContext`가 토글하고 `localStorage`에 저장한다.
저장값이 없으면 OS 설정(`prefers-color-scheme`)을 따른다.

```css
@custom-variant dark (&:where(.dark, .dark *));

:root { --sn-surface-1: #ffffff; ... }
.dark { --sn-surface-1: #0a0a0a; ... }
```

색은 전부 `--sn-*` 변수로 두고 `.dark`에서 **값만 교체**한다.
컴포넌트는 `bg-surface-1` 하나만 쓰면 되고 다크 대응을 따로 하지 않는다.

## Tailwind 유틸

### SpecNote 자체

| 유틸                                          | 값                                            |
| --------------------------------------------- | --------------------------------------------- |
| `bg-surface-1` `bg-surface-2` `bg-surface-3`  | 표면 3단계                                    |
| `bg-hover`                                    | ghost 호버 배경                               |
| `text-fg-1` `text-fg-2` `text-fg-3`           | 텍스트 3단계                                  |
| `text-get-fg` `bg-get-bg` `border-get-border` | 메서드 뱃지 (POST/PUT/PATCH/DELETE 동일 패턴) |

### shadcn 매핑

shadcn 컴포넌트가 쓰는 색 이름을 우리 토큰에 연결해 둔다.
그래서 `<Button>` 등이 **컴포넌트 코드를 고치지 않아도** 우리 색으로 나온다.

| shadcn 유틸                    | 연결된 값                               |
| ------------------------------ | --------------------------------------- |
| `bg-primary`                   | Vercel Blue `#0070f3` — **강조색 채움** |
| `bg-accent`                    | 호버 회색 — **강조색이 아니다**         |
| `bg-background`                | 표면 2 (페이지)                         |
| `bg-card` `bg-popover`         | 표면 1                                  |
| `bg-muted` `bg-secondary`      | 표면 3                                  |
| `text-muted-foreground`        | 텍스트 2                                |
| `border-border` `border-input` | 보더                                    |
| `ring` (포커스 링)             | Vercel Blue                             |
| `bg-destructive`               | DELETE 레드                             |

> **혼동 주의**: shadcn 관례에서 `accent`는 "강조색"이 아니라 **"은은한 hover 배경"**이다.
> 강조색 채움 버튼은 `bg-primary`. `bg-accent`를 쓰면 회색 호버 배경이 나온다.

## 크기

- 헤더 높이 **52px** (모바일 2행 시 약 96px)
- 푸터 높이 **32px** (`h-8`)
- 아이콘 버튼 **32px** (헤더 안에서는 28px)
- 아바타 **32px** (헤더 안에서는 28px), 원형
