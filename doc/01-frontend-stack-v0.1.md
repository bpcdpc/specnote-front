## 기술 스택

| 항목            | 선택                                                       |
| --------------- | ---------------------------------------------------------- |
| 빌드            | Vite + React + TypeScript                                  |
| 스타일          | Tailwind CSS v4 (`@tailwindcss/vite`)                      |
| 컴포넌트        | shadcn/ui (Base UI 프리미티브, Nova 프리셋, Lucide 아이콘) |
| 라우팅          | React Router (`createBrowserRouter`)                       |
| 서버 상태       | TanStack Query                                             |
| 클라이언트 상태 | `useState` / Context                                       |
| 리사이즈        | `react-resizable-panels` (오른쪽 댓글 패널만)              |
| 마크다운 렌더   | `react-markdown` (댓글 코드블록 표시용, 저장은 평문)       |
| 폰트            | Geist(라틴) + Pretendard(한글), CDN                        |
| 다크모드        | `<html>`에 `.dark` 클래스 토글                             |

**설정 메모**

- Tailwind v4는 `tailwind.config.js`가 없다. 토큰은 `styles/index.css`의 `@theme`에 정의한다.
- 경로 별칭 `@/*` → `./src/*`. `tsconfig.json` · `tsconfig.app.json`의 `paths`,
  그리고 `vite.config.ts`의 `resolve.alias` 양쪽에 설정한다.
  (`baseUrl`은 최신 TS에서 deprecated 경고가 뜨므로 넣지 않는다.)
- shadcn은 npm 패키지가 아니라 **코드를 레포에 복사**한다. `components/ui/`의 파일은 우리 코드다.

## 구현 순서

**원칙**: 뼈대 → 레이아웃 → UI → 데이터.

테마는 맨 앞에 배선한다 — 모든 컴포넌트가 토큰에서 색을 가져오므로,
만들면서 라이트/다크를 즉시 검증할 수 있어야 나중에 몰아서 고치는 일이 없다.

화면은 먼저 **목(mock) 데이터**로 만들고, 배관이 준비되면 실제 API 호출로 교체한다.
배관을 먼저 만들면 호출할 화면이 없어 검증할 수 없고, 백엔드 진행 상황에도 묶인다.

## 미결 / 대기

**로그아웃 API**
백엔드에 없다. 기능정의서 · API명세서에 추가 필요.

**댓글은 평문 저장** (`content: string`)
리치 에디터(Tiptap 등)를 쓰지 않는다. 백엔드 `Comment.content`가 평문 한 필드이고,
FR-5.4가 "순수 텍스트 댓글 구조만 유지"로 못 박고 있다.

- `@`/`#` 멘션은 본문 인라인이 아니라 `mentionedUserIds[]` / `mentionedEndpointIds[]` **별도 배열**.
- 코드블록은 **렌더 시** `react-markdown`으로 표시만 한다. 저장 형식은 바뀌지 않는다.
- 이미지 · 동영상 첨부는 스코프 밖(업로드 스토리지·API가 백엔드에 없음).

**드로어 (SpecDetail 모바일)**
후순위. 마감 여유가 생기면 3컬럼 셸이 안정된 뒤 얹는다. 얹으면 가로 스크롤을 대체한다.

**와이어프레임 v0.1과의 차이**
와이어프레임은 양쪽 사이드바 리사이즈로 그려져 있으나,
**실제 구현은 왼쪽 고정 + 오른쪽만 리사이즈**다.
